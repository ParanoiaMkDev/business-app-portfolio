# Business app portfolio

This is a separate, buildless portfolio project, not part of Marketday. All sample businesses, people, products and transactions are fictional. UI is Spanish (es-NI), examples use C$. Discussion and implementation notes are English.

Scope: one portfolio landing page plus Bodega (inventory/sales), Turno (appointments), and Trazo (quotations/orders), with 3–5 usable screens each. Browser-local demo data only, resettable per demo. No backend, live payments, real email sending, credentials, real customer records, or Marketday integration. Use relative asset links compatible with a GitHub Pages project subpath. Do not edit the parent Marketday app.

Design references only: vCard Personal Portfolio, RyanFitzgerald/devportfolio, Tabler, SB Admin 2. No source copied or external code dependencies bundled. Keep third-party inspiration attribution in README; review licenses before adding any library or borrowed assets.

Use proportionate syntax, focused behavior and desktop/phone browser checks. No inherited Marketday baseline. Publishing target is the user's separate public GitHub repository and GitHub Pages, not Sites hosting.
